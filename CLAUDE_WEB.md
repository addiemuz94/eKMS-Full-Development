## Web Portal — Registration Workflow

**Status (Jul 2026 rework + Aug 2026 Registration/UX cleanup + UX/UI/copy audit remediation): implemented and redeployed on `kms-cvt.com`.** Pairing backend + portal must still ship together when API changes land (see `backend/DEPLOY.md`). Recent Registration / Cabinet Management / shell UI changes are `web/dist`-only.

Portal paths:
- `/` — **Dashboard** (Home). **Overview** card (Locations / Cabinets / **Personnel** / Keys), then **Personnel by role**. **Cabinets & location report** is one section: map on top + side list; state/location filter options show cabinet counts `(N)`; selecting a cabinet (map or list) sets the Location report location; PDF download uses that selection. Activity panel below.
- `/registration` — continuous **Location**-scoped wizard (UI **Location** = site/`sites` API). Steps: Location → Key Cabinet → Keys → Key Permission → Setup code (last). Create-time setup code is **carried into wizard state** and shown on the final step (regenerate only when needed / explicit; softer confirm when cabinet is not yet set up). Step gating: location before later steps; ≥1 cabinet before Keys and Setup Code; ≥1 key before Key Permission. Key Permission prefers personnel assigned to the location. **Cabinet number** = API `boxAddress`. Cabinet create/edit sets **Rows** × **Columns** (`nodeRows`/`nodesPerRow`); total capacity = product (max 127) via shared `CabinetLayoutFields`. Keys step embeds `KeysPage` (**Edit layout** + per-slot key add/edit/delete). Timers live under Cabinet Management.
- `/terminals` — **Cabinet Management** hub. Flow: **Location** → **Cabinet** → settings on the right. No top-right “Register key cabinet” (use Registration). Header: Setup status badge + secondary Setup code / Data sync / Move to deleted (**no Edit button** — cabinet identity edits live under settings tab **Cabinet** via `CabinetIdentityForm`, including Rows × Columns). `CabinetSettingsPanel` scrollable tabs: **Cabinet**, Location, Timers & video, **Assign User**, **Keys**, **Key Permission**, **Key Access**. Setup status badges/filters: **Set up / Not set up**. State/province and Location filter options show `(N)` cabinet counts. Removed tabs: Events, Schedules, User groups, Key groups, Two-person approval. `/keys`, `/permissions`, `/key-access`, `/key-groups` redirect here.
- `/personnel` — **User Management** (Cabinets nav): org-wide create/edit/delete accounts. Cabinet **Assign User** tab assigns existing personnel to the location.
- `/settings` — **Website settings**: appearance (System/Light/Dark) + account details; theme toggle lives here (not in the top bar). Sign out is also available here.
- `/login` — Sign in with **account email + password only** (no prefilled email). Splash ~**2s**. If redirected with `?reason=expired`, shows **Your session has expired. Sign in to continue.**
- `/recycle-bin` — **Deleted items**; `/flush-data` — **Erase data**

**Nav / shell (Aug 2026):** Home → **Cabinets** (Registration, Cabinet Management, User Management) → **Reports** (Activity Report, **Activity archive**, …) → **Logs** → **Admin** (Deleted items, Erase data, Website settings). Key Permission and Key Access are tabs inside Cabinet Management only. **Sign out** is always available: sidebar footer (desktop) and mobile top bar (next to Menu); also on `/settings`. Theme stays on `/settings` only. Sidebar **section titles** (Cabinets / Reports / Logs / Admin) are muted uppercase non-clickable labels (no icons). Brand strip still stands out. Company-formal copy: Location, Setup code, Personnel, pickup/return; nav labels **Deleted items** / **Erase data** retained. `/personnel/cabinets`, `/keys`, `/permissions`, `/key-access` → `/terminals`. `/previous-cabinets` → `/activity-archive`.

**Session expiry:** authenticated `web/` API calls that get `401` try `POST /v1/auth/refresh` once (`client.ts`); on failure, clear session and navigate to `/login?reason=expired` (`AuthContext`).

**Cabinet Move to deleted (cascade):** double-confirm then `api.deleteTerminal(id, { cascade: true })` into Deleted items.

**Erase data (`/flush-data`):** category preview → two confirms → permanently delete selected data / full system reset. Super Admin / system accounts + audit retained.

**Key slots & layout (Aug 2026):** Registration / Cabinet Management → **Cabinet** and Keys → **Edit layout** set **Rows × Columns** (`nodeRows`/`nodesPerRow`, total = product, max 127). Keys layout: click free slot to add a key there; assigned slot to edit/move/delete the key. Capacity changes go through Edit layout (not per-slot remove).
**Activity Report / archive:** `/activity-report` — active cabinets only (`cabinetScope=ACTIVE`). Location filter omits locations with **0 active cabinets**; Cabinet filter is active cabinets only. `/activity-archive` — same UI for removed cabinets (`cabinetScope=DELETED`). Pickup & Return, Operation/System/Equipment logs, Home activity, and location PDF checkouts also exclude deleted cabinets. Restore/purge remains under Admin → Deleted items.

**Cabinet behavioral settings:** unchanged API (`terminal_cabinet_settings`); UI under Timers & video.

**Appointment Authorization** was removed from the portal nav/routes and unmounted from the live API (`/v1/admin/appointments*`) — not required by the client.
